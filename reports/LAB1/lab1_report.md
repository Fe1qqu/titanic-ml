## 2. Характеристика набора данных

Набор содержит сведения о пассажирах Titanic. Целевой признак `Survived` обозначает факт выживания пассажира: значение `0` соответствует отсутствию выживания, а значение `1` — выживанию.

Размер набора составляет 891 строку и 12 столбцов. Полных дубликатов строк при выполнении EDA не обнаружено.

| Признак | Содержание |
|---|---|
| `PassengerId` | Идентификатор пассажира |
| `Survived` | Целевой признак: факт выживания |
| `Pclass` | Класс билета |
| `Name` | Имя пассажира |
| `Sex` | Пол пассажира |
| `Age` | Возраст пассажира |
| `SibSp` | Число братьев, сестёр и супругов на борту |
| `Parch` | Число родителей и детей на борту |
| `Ticket` | Номер билета |
| `Fare` | Стоимость билета |
| `Cabin` | Обозначение каюты |
| `Embarked` | Порт посадки |

Сводка типов, числа пропусков, доли пропусков и количества уникальных значений сохранена в `eda_stats.csv`.

## 3. Проверка целостности данных

Проверка выполнена скриптом `scripts/check_data_integrity.py`. Полученный SHA-256 совпал со значением, записанным в `data/hash_manifest.json`.

Размер исходного файла составляет 61 194 байта. При проверке подтверждено, что набор содержит 891 строку и 12 столбцов.

## 4. Результаты разведочного анализа

### 4.1. Пропущенные значения

В наборе обнаружены пропуски в трёх признаках:

| Признак | Число пропусков | Доля пропусков |
|---|---:|---:|
| `Age` | 177 | 19,87 % |
| `Cabin` | 687 | 77,10 % |
| `Embarked` | 2 | 0,22 % |

Наибольшая доля пропусков приходится на признак `Cabin`. При подготовке данных необходимо отдельно рассмотреть целесообразность использования этого признака и способ обработки его пропусков.

График: [Распределение пропусков](figures/missing_values.png).

### 4.2. Распределение целевого признака

| Значение `Survived` | Число пассажиров | Доля |
|---|---:|---:|
| 0 — не выжил | 549 | 61,62 % |
| 1 — выжил | 342 | 38,38 % |

Целевые классы представлены неодинаково. Это различие следует учитывать при оценке качества моделей и выборе метрик.

График: [Распределение целевого класса](figures/class_distribution.png).

### 4.3. Числовые признаки

Для числовых признаков рассчитаны количество наблюдений, среднее значение, стандартное отклонение, минимум, квартильные значения и максимум. Полные результаты находятся в `eda_stats.csv`.

Для признака `Age` статистики рассчитываются только по заполненным значениям. Его средний возраст составляет приблизительно 29,70 года, медиана — 28 лет.

Для признака `Fare` среднее значение составляет приблизительно 32,20, а медиана — 14,45. Различие между средним и медианой указывает на асимметрию распределения стоимости билетов и наличие наблюдений с высокими значениями.

Графики: [Распределение возраста](figures/age_distribution.png) и [распределение стоимости билетов](figures/fare_distribution.png).

### 4.4. Корреляции и пропуски в разрезе целевого признака

Корреляционная матрица сохранена в `figures/correlation_heatmap.png`. Она используется для предварительного изучения линейных связей между числовыми признаками. Корреляция сама по себе не доказывает причинно-следственную связь.

Дополнительно построен график доли пропусков в `Age`, `Cabin` и `Embarked` отдельно для каждого значения `Survived`: `figures/missingness_by_survival.png`.

Различия в долях пропусков могут указывать на связь механизма отсутствия данных с другими переменными. Однако по одному такому графику нельзя однозначно установить механизм пропусков или сделать вывод об утечке целевого признака.

## 5. План разделения данных

Для последующих экспериментов предусмотрено разделение на обучающую и тестовую выборки в соотношении 80:20 с фиксированным `random_state=42` и параметром `stratify=y`. Стратификация нужна для сохранения приблизительно одинаковых долей классов в обеих выборках.

Разделение и проверка отсутствия пересечения индексов выполняются скриптом `scripts/check_leakage.py`. Целевой признак `Survived` должен быть исключён из матрицы входных признаков.

При подготовке данных статистики для заполнения пропусков следует вычислять только на обучающей выборке, после чего применять полученные значения к тестовой выборке.
