## 1. Использование инструментов искусственного интеллекта

При выполнении лабораторной работы № 1 ChatGPT использовался для консультаций по организации Git-репозитория, настройке прекоммитных проверок, интерпретации результатов EDA, проверке структуры отчёта и подготовке документации.

Предложения, полученные от ИИ, проверялись на соответствие фактическому состоянию проекта. Команды выполнялись в локальном окружении, а результаты проверок оценивались по фактическому выводу инструментов.

## 3. Проверки лабораторной работы № 1

- [ ] Проверить актуальное состояние основной ветки.
- [ ] Убедиться, что защита `main` настроена и изменения проходят через Pull Request.
- [ ] Выполнить `pre-commit run --all-files`.
- [ ] Проверить целостность исходного набора данных.
- [ ] Повторно выполнить EDA и проверить воспроизводимость результатов.
- [ ] Проверить наличие отчёта, таблиц, графиков и журнала негативных тестов.
- [ ] Проверить конфигурацию лабораторной с использованием Pydantic.
- [ ] Проверить корректность ссылок и разметки отчёта.
- [ ] Выполнить критическую оценку результатов проверки ИИ по требованиям курса.

## 4. Подтверждение результатов

Результаты проверок должны подтверждаться командами, исходными файлами, отчётами, графиками, историей Git и результатами тестирования. Непроверенные пункты не следует отмечать как выполненные.
